# 八字五行排序算法

这是八字五行力量排行数学算法的资料与验算记录。
我利用自己数学专业的知识设计了一套算法来计算八字的五行力量排行：
一、写出八字的五行力量评分，天干一个算10分，地支按照藏干力量占比来分配分数（总分10分），按照木火土金水的顺序写出列向量E_0，写出之后验证五行力量分数和为80
二、给定五行生克泄耗矩阵T，为便于书写，矩阵T在项目资料中以图片形式呈现
三、给定月令季节矩阵S，十二个月的月令季节矩阵同样均已在项目资料中以图片形式呈现
四、最终五行力量向量U=T·S·E_0

## 网页计算器

本仓库现在包含一个无第三方运行依赖的静态计算器。直接输入年、月、日、时四柱，不从出生日期推算，也不调用 AI 或任何付费 API。

- 支持逐柱输入，或在任意输入框粘贴完整八字。
- 展示五行力量排序、最终列向量 U，以及日主五行的名次。
- 展开计算过程后，可查看 E₀、S·E₀、当月矩阵 S、矩阵 T 和八个字的计分明细。
- 严格使用项目资料中的参数，保留负数，先按完整精度排序，再格式化显示。
- 精确同分显示为并列；不擅自把五行名次解释为身强身弱结论。
- 输入只在浏览器本地处理，不保存、不上传。

### 本地预览

已安装 Node.js 20 或以上版本时，双击根目录的 `本地预览.cmd`，然后打开终端显示的地址。也可以在仓库目录运行：

```powershell
npm run dev
```

不需要执行 `npm install`。不要直接双击 `index.html`；ES 模块应通过本地预览服务或 GitHub Pages 加载。
