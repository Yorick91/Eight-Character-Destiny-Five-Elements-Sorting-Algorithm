# 八字五行排序算法

这是八字五行力量排序数学模型及本地网页计算器。输入年、月、日、时四柱后，浏览器按木、火、土、金、水顺序计算 `U = T·S·E₀`，不从出生日期反推四柱，也不上传输入内容。

## 当前算法

### 1. E₀ 位置加权

- 四个天干继续各计 `10` 分。
- 地支总分改为：年支 `15`、月支 `30`、日支 `20`、时支 `25`。
- 每个地支内部继续按原藏干比例分配，例如丑为己 6、辛 3、癸 1，申为庚 6、壬 3、戊 1。
- 因此每盘基础 `E₀` 总和固定为 `40 + 15 + 30 + 20 + 25 = 130`。

### 2. 三合守恒转移

三合发生在 `E₀` 层，先转移再乘月令矩阵 `S` 和生克矩阵 `T`。来源藏干扣除多少，目标五行增加多少，保持总量守恒：

| 情形 | 基础 λ | 例子 |
|---|---:|---|
| 三支齐全 | `0.60` | 亥卯未合木、寅午戌合火、丑巳酉合金、申子辰合水 |
| 半合且含帝旺支 | `0.30` | 申子、子辰、寅午、午戌等 |
| 半合但不含帝旺支 | `0.10` | 申辰、亥未、寅戌等 |

有效 λ 还会按配置修正：月令参与 `×1.20`、天干透出本局五行 `×1.15`、隔位 `×0.70`、普通冲破 `×0.50`、外部克制 `×0.50`、六合牵动 `×0.50`；冲掉帝旺支时该候选合局直接失效。多个合局按有效 λ 从大到小处理，同一位置同一藏干来源只转移一次。

### 3. 后续矩阵

1. 汇总位置加权后的基础 `E₀`。
2. 在 `E₀` 层执行三合转移，得到守恒后的 `E₀`。
3. 按月支使用十二个月令季节系数 `S`。
4. 计算 `U = T·S·E₀`，保留全精度后再排序和显示。

## 网页计算器

- 支持逐柱输入，也支持在任意输入框粘贴完整八字。
- 展示五行排序、最终向量、基础与转移后的 `E₀`、三合候选及守恒误差。
- 保留负数；排序使用未格式化的原始数值；相同数值显示并列。
- 无第三方运行依赖。Node.js 20 或以上版本可运行 `npm run dev`，不要直接双击 `index.html`。

## 验证记录

验证使用研究目录 `D:\Academic reseach interests\八字五行力量排行数学算法` 中的八字资料库，先搜索 λ，再用留出集复核，并检查每盘 `E₀` 总量与转移守恒。当前结果：

- 解析记录 `69` 条；明确标签评分集 `48` 条；训练集 `30` 条；印强专题留出集 `18` 条。
- 最优基础 λ：三支齐全 `0.60`、含帝旺半合 `0.30`、拱合 `0.10`。
- 训练集准确率 `70.00%`，平衡准确率 `69.91%`；留出集准确率 `72.22%`，平衡准确率 `68.46%`。
- 全部有标签记录准确率 `70.83%`，平衡准确率 `70.63%`；外部验证例 `2/2`。
- 所有检查盘 `E₀` 总和为 `130`，三合转移守恒误差为 `0`。
- 旧的四支等权版本在当前样本上的拟合率更高，因此新位置权重是按需求实现并完成验证，不能宣称已经被样本证明更准确。

详细验证留痕见 `validation/VALIDATION_LOG.md` 与 `validation/validation-results.json`。研究目录中的 `algorithm.js` 和 `validation/validate.js` 保留了可复核的 Node.js 版本实现与验证脚本。
